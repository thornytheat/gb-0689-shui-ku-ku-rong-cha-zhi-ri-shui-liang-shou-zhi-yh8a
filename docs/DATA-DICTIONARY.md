# 水位与水量定义

id、station为字符串。time含时区，统一UTC，日账在+08:00午夜拆分。level单位m；inflow/outflow单位m3/s或L/s，归一m³/s；空值不等于零。入流、出流允许单侧为空（NULL/-/N/A等哨兵），归一为None保留；两侧同时为空无法推算，按MISSING隔离。负流量与曲线外水位隔离。
curve为[[水位,库容],...]，水位及库容必须严格递增，库容非负，单位m与m³。只对范围内水位分段线性插值，端点允许。
同站同刻按version最高记录采信，同版不同值全部隔离。重复旧版有独立证据。输入=采信+隔离；原始行号保留。
相邻观测间以梯形积分计算流量体积，超过max_gap_hours则不插补。缺测一侧的相邻段该侧不积分，观测覆盖时长（in_obs_hours/out_obs_hours）单列，绝不当零或插值冒充观测。日界处先线性插出流量与水位，再分别积分及按曲线换算库容。日账是已覆盖时段的收支，覆盖不足24h始终待补测。
日账每个水量分两列：观测水量（in_obs_m3/out_obs_m3）与推算补量（in_fill_m3/out_fill_m3），合计列in_m3/out_m3=观测+推算。整日库变可观测（storage_hours=24）且仅一侧缺观测时，按水量平衡由库容变化约束补齐：总入库=库变+观测出库，入库补量=总入库-已观测入库；总出库=观测入库-库变，出库补量=总出库-已观测出库。fill_source记录补齐来源（库容变化约束·补入库/补出库，无补齐为“无”），state标“补齐”。推算出负水量、库变不完整或两侧同缺时不推算，保留“缺测”。推算值不进入观测列，不冒充原始观测。
日收支差=库容变化-入库合计+出库合计；补齐日因约束构造残差为0，仍在异常复核标FILL=推算待核，不自动通过。绝对值超过tolerance_m3需复核。缺测优先于补齐与超差。无蒸发降雨、地下渗漏及外部调度模型，差额不自动认作漏损。
数值为Decimal字符串，日切与整段积分容许1e-9m³以内十进制除法尾数。规则参数和输入摘要参与幂等ID；批次原子保存，复核版本冲突返回409。
日账发布（POST /api/m5/publish）按(station,date)唯一写入ledger表，整笔事务：任一行失败全部回滚，旧版日账保留，失败返回PUBLISH_FAILED(500)。重跑同一天靠INSERT OR IGNORE跳过，已确认日期不重复补量。补齐失败后POST /api/m5/resume（可仅传run_id，取回发布时留存原文重算）从已确认日期续跑，仅发布新增日期。

原始到达序小于此前最大事件时刻的测次标记arrival=迟到，仍保留并按事件时间排序积分，迟到不会推进水位回退。
